# رواد بلس — تطبيق Flutter

هذا مشروع Flutter حقيقي لنفس تطبيق "رواد بلس" اللي بنيناه كنموذج HTML، بنفس نظام الأدوار الخمسة.

## تشغيل المشروع

```bash
flutter pub get
flutter run
```

يحتاج Flutter SDK بإصدار حديث نسبيًا (3.22 أو أحدث يفضّل). لو عندك إصدار أقدم من كذا
وواجهت مشاكل توافق، قولي وهظبط الكود على إصدارك.

⚠️ **ملاحظة مهمة:** الكود اتكتب هنا من غير Flutter SDK متاح للتجربة الفعلية (البيئة دي
معندهاش وصول لتنزيله)، فمعمول عليه مراجعة يدوية دقيقة (فحص التوازن بين الأقواس، تطابق
الاستيرادات، توافق أسماء الـ API) لكن مش مضمون 100% إنه هيتبني من أول مرة من غير أي
تعديل بسيط. أول حاجة تعملها: `flutter pub get` ثم `flutter run` وابعتلي أي خطأ يظهر
لو حصل وهصلحه فورًا.

## هيكل المشروع

```
lib/
  main.dart                    نقطة الدخول + شاشة تسجيل الدخول أو الـ Shell
  theme/app_theme.dart         الألوان والخطوط (نفس هوية النسخة التجريبية)
  models/models.dart           الموديلات: Trip, BusInfo, Traveler, RoomAssignment...
  state/app_state.dart         إدارة الحالة العامة (Provider) — الدور، البرامج، الباصات...
  widgets/shared_widgets.dart  ودجتس مشتركة (StatChip, StatusPill, InfoRow...)
  screens/
    auth/login_screen.dart             تسجيل الدخول + اختيار الدور
    root_shell.dart                    الـ Shell الرئيسي (Bottom Nav حسب الدور)
    dashboard/                         لوحة التحكم + الحجوزات (المالك/مدير الرحلات)
    trips/                             البرامج + التفاصيل + تعيين فندق/باص/مشرف
    wizard/                            معالج إنشاء برنامج عمرة (5 خطوات)
    hotel_manager/                     لوحة وشاشات مشرف الفندق (تسكين الغرف)
    bus_supervisor/                    لوحة وشاشات مشرف الباص (حضور وغياب)
    profile/                           شاشة "حسابي"
```

## اللي اتبنى في هذه النسخة

- نظام الأدوار الخمسة كامل مع تسجيل دخول واختيار الدور
- Bottom Navigation ديناميكي يتغيّر حسب الدور
- شاشة "البرامج" بالأزرار الأربعة وفلتر الفئة وزرار الإضافة (للمالك بس)
- معالج إنشاء برنامج عمرة بخطواته الخمس
- تعيين الباصات (فعليًا تقدر تضيف/تشيل معتمرين)
- تعيين الفندق وتعيين المشرفين
- تسكين الغرف الفعلي لمشرف الفندق (بالدور ورقم الغرفة)
- حضور وغياب فعلي لمشرف الباص
- شاشة حسابي بقائمة تتغيّر حسب الدور

## اللي لسه محتاج نكمله (زي ما عملنا بالظبط مع نسخة الـ HTML، خطوة خطوة)

- شاشات: الفنادق، النقل والطيران، التقارير، بيانات الشركة، الإشعارات، المستخدمون والمشرفون
- فورم إضافة معتمر وفورم إضافة فندق كاملين
- ربط حقيقي بـ Backend/API بدل البيانات التجريبية الثابتة في `app_state.dart`
- حفظ الحالة بين الجلسات (شرائح التخزين المحلي)
